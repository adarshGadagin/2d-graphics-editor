The Line Equation
You know the slope formula:

slope = (y2 - y1) / (x2 - x1)
This means: how much y changes for every 1 step in x

Derive Step by Step
Think of it this way.

At the starting point, you know:

x starts at → x1
y starts at → y1
As x moves forward, y changes by slope each step.

So:

y = y1 + slope * (how far x has moved from start)
"How far x has moved from start" = (x - x1)

Therefore:

y = y1 + slope * (x - x1)
Why y1 and x1, NOT y2 and x2?
Simple rule: use your starting point, not ending point.

You are building the line forward from the start.

If you use	Meaning
y1, x1 ✅	Start from beginning — CORRECT
y2, x2 ❌	Start from the end — WRONG

Bug: Wrong Operator
In main(), p is a variable, not a pointer:

c

p->picture        // ❌ -> is for pointers

So change all -> to .:

When to Use . vs ->
c
picture p;     →  p.field        // direct variable
picture *p;    →  p->field       // pointer to variable
You used -> correctly everywhere else because your functions take picture *p as parameter. But in main you declared picture p directly!
